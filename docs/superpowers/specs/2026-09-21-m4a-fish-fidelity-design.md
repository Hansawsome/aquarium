# M4a 설계 — 물고기 정밀화 (실사 반복 1단계)

작성일: 2026-09-21 · 상태: 사용자 위임, 결정은 이 문서에 기록

## 왜 이것부터인가

M4로 묶여 있던 항목은 서로 독립적인 다섯 덩어리였다: 물고기 모델 정밀화, 산호·조명·후처리, 무리(보이즈) 행동, 소품 충돌, 수직 전환 롤 제거. 한 계획으로 묶으면 무엇도 끝나지 않으므로 쪼갠다.

- **M4a (이 문서)**: 물고기 지오메트리와 재질. 화면에서 아이가 계속 보는 대상이고, 지금 가장 "장난감 같은" 부분이다.
- M4b: 산호·바위 품질, 조명·후처리(색보정·심도·부유 입자).
- M4c: 무리 행동, 소품 충돌, 수직 전환 롤 제거.

## 현재 상태와 목표

현재 물고기는 늘린 UV 구를 꼬리 쪽으로 가늘게 만든 몸통 + 평면 지느러미 판이고, 재질은 베이크한 베이스 컬러 한 장에 러프니스 상수 0.35다. 눈·입·아가미·비늘이 없어 가까이서 보면 색칠한 캡슐로 읽힌다.

목표는 **같은 거리에서 "물고기처럼 보이는" 수준**이다. 사진 수준을 노리지 않는다. 판정은 M1부터 써 온 방식 그대로: 같은 장면·같은 카메라로 개선 전후 스틸을 나란히 놓고 사용자가 본다.

## 결정 사항 (아쿠부장 판단, 2026-09-21)

| 항목 | 결정 | 이유 |
|---|---|---|
| 몸통 형태 | 구 스케일링을 버리고 **프로파일 곡선 기반 회전·로프트**로 만든다. 종마다 `profile(t)`(코→꼬리 0..1에서의 높이 비율)와 `width(t)`를 함수로 주고, 단면은 타원이 아니라 등·배가 다른 비대칭 형태 | 실루엣이 실사 인상의 대부분이다. 구를 늘리면 머리와 꼬리가 같은 곡률이라 물고기가 아니라 캡슐로 읽힌다 |
| 눈 | 별도 구 메시(안구) + 홍채·동공을 절차 텍스처로. 좌우 대칭, 머리 프로파일에 맞춰 살짝 파묻는다 | 눈이 없으면 무엇을 해도 장난감이다. 가장 싼 실사 레버 |
| 입·아가미 | 입은 프로파일 곡선에 얕은 홈, 아가미 덮개는 텍스처(베이스 컬러 + 노멀)로 표현 | 지오메트리로 파면 리깅·가중치가 흔들린다. 텍스처가 비용 대비 효과가 크다 |
| 지느러미 | 평면 판 대신 **두께가 가장자리로 갈수록 얇아지는 막 + 지느러미살(ray) 융기**. 살은 노멀맵으로 굽는다 | 지금 지느러미는 종이 조각처럼 보인다. 두께 구배와 살 융기만으로 크게 달라진다 |
| 텍스처 | 베이스 컬러에 더해 **노멀맵(비늘·지느러미살·아가미)과 러프니스맵**을 함께 베이크한다. 비늘은 Voronoi 기반 절차 패턴 | 단색 알베도만으로는 수중 조명에서 평평하다. 노멀·러프니스가 들어가면 빛무늬가 표면을 타고 흐른다 |
| Unreal 재질 | `M_<Species>`를 베이스 컬러 + 노멀 + 러프니스 + **약한 서브서피스**(얇은 지느러미 투과감) + 스페큘러 조정으로 확장 | 수중에서 지느러미가 빛을 통과시키는 느낌이 실사감을 크게 올린다 |
| 폴리곤 예산 | 몸통 2~4k 정점(현재 1.15k), 눈 포함 5k 이하. 36마리 + 플레이어 기준 총 20만 정점 이하 | 현재 평균 102 fps / p95 10.2 ms라 여유가 있다. M4a 후 같은 방법으로 재측정해 회귀를 확인한다 |
| 적용 범위 | 5종 전부 | 한 종만 고치면 장면 안에서 품질이 튄다 |
| 호환성 | 본 이름·축·cm 단위·`Root` 비변형 규약은 그대로. FBX 계약이 깨지면 Unreal 쪽이 전부 무너진다 | M1~M3의 모든 테스트가 이 계약에 걸려 있다 |

검토한 대안: 조각(sculpt) 기반 수작업(재현 불가, 프로젝트 원칙 위반), 외부 무료 실사 모델 도입(라이선스·리깅 규약 불일치, 5종을 맞추기 어려움), 셰이더만 개선(실루엣이 그대로라 효과 제한적).

## 구성 요소

### `fishlib` 확장
- `build_body_profile(name, spec)` — `length`, `profile(t)`(등 높이), `belly(t)`(배 깊이), `width(t)`, `sections`(기본 28), `ring_segments`(기본 20)로 로프트한다. 단면은 `z = lerp(belly, profile)`를 따르는 타원의 상하 비대칭 형태. 머리(t≈0)는 둥글게 닫고 꼬리(t≈1)는 얇게 수렴시킨다. 기존 `build_body`는 남겨 둔다(산호 등 다른 용도).
- `add_eye(body_spec, side, position_t, radius, sink)` — 안구 구를 만들어 좌우에 배치하고 머리 안쪽으로 `sink`만큼 밀어 넣는다. 별도 머티리얼 슬롯을 쓰지 않고 같은 UV 공간에 베이크한다.
- `add_membrane_fin(name, outline, thickness_fn, rays)` — 외곽선(비율 좌표)과 두께 함수로 막을 만들고, `rays`개의 지느러미살을 따라 융기를 준다(베이크 시 노멀에 반영).
- `bake_maps(body, mat_name, build_nodes, base_name, export_dir, size=2048)` — 베이스 컬러·노멀·러프니스를 한 번에 베이크한다. 노멀은 하이폴리 대신 **머티리얼 범프 → 노멀 베이크**(비늘·살 패턴)로 만든다.
- `scale_pattern(nt, uv_socket, cell_size, sharpness)` — Voronoi 기반 비늘 높이/러프니스 패턴 헬퍼.

### 종 스펙 확장
각 `make_<species>.py`의 spec에 `profile`, `belly`, `width` 함수와 `eye`(위치·반경), `fins`(외곽선·살 개수), `scale_cell`(비늘 크기)을 추가한다. 색 함수는 그대로 쓰되 비늘 패턴을 곱한다.

### Unreal
- `import_fish.py`: 종마다 `T_<name>_BaseColor`(sRGB), `T_<name>_Normal`(sRGB off, TC_NORMALMAP), `T_<name>_Roughness`(sRGB off)를 임포트하고, `M_<name>`을 베이스 컬러 + 노멀 + 러프니스 + 서브서피스(`Subsurface Color`, `Opacity` 0.15 상수, 셰이딩 모델 `Subsurface`) + 스페큘러 0.4로 구성한다.
- 기존 `used_with_skeletal_mesh`, 물리 에셋, 본 검증은 그대로.

## 검증

| 계층 | 검증 |
|---|---|
| 에셋 계약 | 5종 모두 FBX 본 목록이 `Root, Spine0..5, Tail, PecL, PecR`로 불변, +X 머리, cm 단위, `unweighted=0`, `rootMaxW=0` — 지금의 가드 그대로 |
| 폴리곤 | 종마다 정점 수를 출력하고 5k 이하를 단언 |
| 텍스처 | 세 장이 모두 2048²로 생성되고, 노멀맵이 평평하지 않은지(픽셀 분산 > 임계) 스크립트로 확인 |
| Unreal | 기존 Automation 37개 유지. 머티리얼에 노멀·러프니스 슬롯이 연결됐는지 임포트 스크립트가 출력으로 보고 |
| 성능 | `scripts/measure_m2b_perf.sh`를 그대로 돌려 M2b(평균 102.5 fps, p95 10.22 ms) 대비 회귀를 기록. 평균 60 fps 아래로 떨어지면 폴리곤·텍스처 해상도를 조정하고 다시 측정 |
| 시각 | **같은 카메라·같은 시드로 개선 전/후 스틸을 나란히** 만든다(좌: M3 캡처, 우: M4a). 근접 스틸도 한 장(카메라를 물고기 1 m 앞에 두고) |

## 데이터·오류 처리

- 베이크가 실패하거나 노멀맵이 평평하면 스크립트가 `raise`한다(지금의 `_OK` 마커 규약 유지).
- 정점 예산을 넘으면 `sections`/`ring_segments`를 줄여 재시도하고, 그래도 넘으면 실패로 보고한다.
- 5종 중 하나라도 본 계약이 깨지면 그 종만 실패시키고 나머지는 계속 진행하지 않는다(장면이 섞이면 판단이 불가능하다).

## 범위 밖

산호·바위 품질과 조명·후처리(M4b), 무리 행동·소품 충돌·수직 롤(M4c), 클릭 도망(M5), 패키징(M6).
