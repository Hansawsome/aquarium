# PRD — Aquarium

작성일: 2026-09-19 · 상태: 논의 반영 초안, 문서 검토 대기

## 목적

초등학생이 별명을 입력하고 산호초 바다에 들어가 자신의 물고기를 조종하며 바닷속 분위기를 경험한다. 물고기의 사실적인 형태와 움직임, 잠수부가 수경 너머로 보는 듯한 수중 시야를 우선한다.

## 사용자와 실행 환경

- 1차: Apple M5, 메모리 24GB 맥북프로에서 실행하는 네이티브 앱.
- 2차: 태블릿 대응. 운영체제와 대상 기기는 해당 단계에서 확인한다.
- 한 기기의 한 세션에서 사람이 제어하는 물고기는 한 마리다. 나머지는 자동 유영한다.

## 확정 요구사항

| ID | 요구사항 |
|---|---|
| P-01 | 이름 또는 별명만 입력해 입장한다. 계정·비밀번호는 요구하지 않는다. |
| P-02 | 입장할 때 이용 가능한 물고기 중 한 마리를 무작위 배정한다. |
| P-03 | 내 물고기 위에 입력한 이름을 표시한다. |
| P-04 | 방향키로 화면 기준 상하좌우 이동한다. |
| P-05 | 주변 물고기는 자율적으로 움직인다. |
| P-06 | 카메라는 잠수부 위치에 머물고 내 물고기를 추적하지 않는다. |
| P-07 | 햇빛이 들어오는 얕은 태평양 산호초 바다를 표현한다. |
| P-08 | 태블릿에서는 물고기를 터치하면 도망가는 애니메이션이 나타난다. |
| P-09 | 무료 에셋과 Blender 등 제작 도구로 구현한다. |
| P-10 | Superpowers 개발 절차와 TDD를 적용하고 GitHub aquarium에 기록한다. |

## 기본 설계값 — 수정 가능

- 입장은 인증이 아닌 로컬 세션 시작이다. 종료하면 별명을 폐기하고 재입장하면 다시 배정한다.
- 내 물고기와 주변 물고기 모두 터치 반응 대상이다. 맥북에서는 클릭으로 같은 반응을 검증한다.
- 깊이 방향은 자동으로 약하게 변화시켜 방향키 조작을 단순하게 유지한다.
- 첫 장면 검증에서는 물고기 한 종으로 시작하고, 무작위 배정 완료 시점에는 적어도 두 가지 물고기 정의를 갖춘다.
- 점수·미션·먹이주기·성장·멀티플레이·교사 계정·클라우드 저장은 초기 범위에 넣지 않는다.

## 경험 흐름

실행 → 산호초 바다 배경과 별명 입력 → 유효한 별명으로 입장 → 물고기 배정 및 이름 표시 → 방향키 탐험 또는 클릭 반응 → 나가기 → 입력 화면.

## 그래픽 목표와 완료 판정

실사 수준은 목표이며 고해상도 출력만으로 달성한 것으로 판단하지 않는다. 물고기 표면, 몸통·지느러미 움직임, 빛무늬, 수중 산란과 거리감이 어우러져야 한다.

첫 시각 검토는 한 장면·한 종의 물고기·유영 영상으로 진행한다. 사용자가 원하는 분위기인지 확인하고 확장한다. 성능은 SRS의 실제 기기 측정 기준으로 따로 판정한다.

## 출시 단계

1. 산호초 장면과 한 마리 물고기의 시각·성능 검증.
2. 이름 입력, 무작위 배정, 방향키 제어, 자동 유영, 클릭 도망 반응을 포함한 macOS 시제품.
3. 품질 조정과 macOS 패키징 검증.
4. 대상 태블릿 선정 후 터치·그래픽 품질·배포 방식 검증.
