# M6 성능 — SRS 공식 판정 (패키지 개발 빌드)

작성일: 2026-09-21 · 커밋: 5a6304e

**이것이 이 프로젝트의 첫 SRS 공식 성능 판정이다.** M1~M5의 모든 수치는 에디터 빌드에서 나왔고,
SRS 38행은 "패키징한 개발 빌드에서 30초 예열 후 3분"을 요구한다.

## 측정 조건

| 항목 | 값 |
|---|---|
| 빌드 | 패키지 **Development** (`scripts/package_mac.sh`), 쿡·pak 적용 |
| 기기 | Apple M5 (10 physical cores, 24 GB) |
| 해상도 | 1920×1080 내부 = 출력, 업스케일 없음, `-ForceRes` |
| 그래픽 설정 | 커밋된 `DefaultEngine.ini` 그대로 (`GridPixelSize=4`, `GridSizeZ=128`) |
| 장면 | `ReefM1` — 제어 1 + 배경 36 + 프롭 22 |
| 예열 / 측정 | 30초 / 180초, 2회 |
| 스크립트 | `scripts/measure_package_perf.sh` (`RUN_SEC` 기본 210, warm-up+180 미만 거부) |

**장면이 SRS 37행보다 무겁다.** SRS는 "제어 1 + 배경 19"를 적었고 실제는 배경 36마리다
(M2b에서 PRD의 30~40마리 요구를 따랐다). 게이트를 유리하게 바꾸지 않았다는 뜻이므로 그대로 판정한다.

## 결과

| 실행 | 평균 fps | p95 프레임 시간 | 실측 구간 | 샘플 |
|---|---|---|---|---|
| 1회차 | 61.45 | 16.58 ms | 180.7 s | 11104 |
| 2회차 | 61.47 | 16.58 ms | 180.8 s | 11115 |
| **평균** | **61.46** | **16.58 ms** | | |

두 실행 중 60 fps 아래로 떨어진 실행은 **없다.**

## SRS 게이트 판정

| 기준 | 목표 | 실측 | 판정 |
|---|---|---|---|
| 평균 fps | ≥ 60 | 61.46 | 통과 |
| p95 프레임 시간 | ≤ 22 ms | 16.58 ms | 통과 |

**판정: 통과**

## 이 수치는 천장이 아니라 바닥이다 (중요)

프레임 시간 분포를 보면 이 측정이 **표시 주사율에 묶여 있다**:

| | min | p05 | p50 | p95 | p99 | max |
|---|---|---|---|---|---|---|
| 1회차 | 3.19 | 15.83 | 16.11 | 16.58 | 17.55 | 51.77 ms |
| 2회차 | 2.93 | 15.82 | 16.11 | 16.58 | 18.15 | 49.91 ms |

전체 프레임의 **73%가 16.0~17.0 ms 한 띠에 몰려 있고** 최소 프레임 시간은 3 ms다. 즉 엔진은
3 ms만에 그릴 수 있는 프레임도 16.6 ms에 맞춰 내보내고 있다 — 60 Hz 제시 상한이다.
그러므로 61.46 fps는 **이 장면이 낼 수 있는 최대치가 아니라 상한에 눌린 값**이며, 실제 여유는
이 측정으로는 보이지 않는다. 게이트 판정에는 영향이 없다(목표가 "≥ 60"이므로 상한에 눌린
채로도 목표를 넘는다). 다만 "61.5 fps이므로 여유가 1.5 fps뿐"이라고 읽으면 틀린다.

## 에디터 빌드와의 관계

M5의 63.50 fps는 **에디터 빌드**이며 쿡·셰이더·텍스처 스트리밍 설정이 모두 달라 직접 비교할 수
없다. 참고로만 적고 게이트 판정에는 쓰지 않는다.

## 예비 레버

`r.VolumetricFog.GridSizeZ` 128 → 64 (M4b 측정 +17.1 fps)는 M4b·M4c·M5에서 일부러 아껴 두었다.
**사용 여부: 쓰지 않았다** — 두 실행 모두 평균 60 fps와 p95 22 ms를 통과했고, 위에서 보듯
측정 자체가 제시 상한에 눌려 있어 레버를 써도 이 수치가 올라가지 않는다. 커튼 3→1과 SSAO도
건드리지 않았다. 세 레버 모두 손대지 않은 채 출하한다.

## 노이즈

실행 간 노이즈 바닥은 약 1.3 fps. 두 실행의 차이는 **0.02 fps**로 노이즈 바닥보다 한참 아래다.
두 실행은 사실상 같은 값이며, 차이를 신호로 읽어서는 안 된다.

## 측정에서 걸린 함정 (기록)

패키지 앱은 `com.apple.security.app-sandbox`로 서명되어 있고 파일 접근 엔타이틀먼트가 없다.
그래서 `-AquariumFrameStats=<저장소 경로>`는 **조용히 실패한다** — 실행은 정상 종료하고 파일만
남지 않아 크래시와 구분이 안 된다. 실제로 1회차 첫 시도가 이렇게 죽었다. 스크립트는 이제
컨테이너 안(`~/Library/Containers/com.YourCompany.Aquarium/Data/Documents`)에 쓰게 하고
끝난 뒤 저장소로 옮긴다.
