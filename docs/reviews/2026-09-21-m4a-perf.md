# M4a 성능 재측정 (2026-09-21)

M4a(로프트 바디·눈·막 지느러미·2048² 3장 PBR 텍스처)로 다시 만든 물고기가 들어간 뒤
ReefM1 레벨의 프레임 시간을 `scripts/measure_m2b_perf.sh`로 그대로 다시 측정했다.
개발 전용 `-AquariumFrameStats` 플래그를 쓴다.

**재측정 사유.** 이 문서에 처음 적혔던 수치(평균 102.0 fps / p95 10.07 ms, 커밋 `85051c7`)는
바위 3종(`M_boulder_01`, `M_rock_07`, `M_rock_09`)의 머티리얼이 컴파일에 실패해
텍스처 없는 기본 회색 머티리얼로 그려지던 상태에서 측정한 값이다. 즉 실제로 출시될 장면의
측정값이 아니었다. 머티리얼을 고친(커밋 `4d7f736`) 뒤의 장면으로 다시 측정한 값이
아래 "결과"이며, 이전 수치는 폐기한다.

## 측정 조건

- 해상도: 1920x1080 (`-game -windowed -ForceRes`), 텍스처 스트리밍 끔
- 씬: 배경 물고기 36마리(5종) + 프롭 14개 + 플레이어 물고기 1마리
- 실행 시간 95초 중 앞 30초(워밍업: 셰이더 컴파일·스트리밍)는 버림
- `-benchmark`는 사용하지 않음 — 고정 타임스텝이 되어 DeltaSeconds가 상수가 되므로 측정에 쓸 수 없다
- 커밋: `2c654e0` (바위 머티리얼 수정 이후)
- 머신: Apple M5

## SRS 목표 대비

SRS 성능 목표는 "평균 60fps, 95백분위 ≤ 22 ms"이며, **판정은 M6**에서 한다.
이 수치는 에디터 바이너리로 측정한 중간 참고값이다. 평균 100.9 fps는 목표의 1.7배이고
p95 10.27 ms는 예산 22 ms의 절반 이하다.

## M2b 기준선 대비

| 항목 | M2b (2026-09-20, `c945154`) | M4a (2026-09-21, `2c654e0`) | 차이 |
| --- | --- | --- | --- |
| 평균 fps | 102.5 | 100.9 | -1.6 (-1.6%) |
| 중앙값 fps | 104.5 | 102.7 | -1.8 |
| 95백분위 프레임 시간 | 10.22 ms | 10.27 ms | +0.05 ms |
| 99백분위 프레임 시간 | 10.83 ms | 10.94 ms | +0.11 ms |
| 최대 프레임 시간 | 45.61 ms | 47.79 ms | +2.18 ms |

폴리곤이 크게 늘고 텍스처가 종당 1장에서 3장(2048²)으로 늘었으며 바위 3종의 텍스처도
이제 실제로 샘플링되지만, 평균 fps 차이는 1.6%로 측정 노이즈 수준이고 p95는 0.05 ms
차이다. 이 씬은 여전히 GPU 바운드가 아니다. 평균 60 fps 기준을 크게 웃돌므로
폴리곤·텍스처를 줄일 이유가 없다.
