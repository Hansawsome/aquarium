# M4a 성능 재측정 (2026-09-21)

M4a(로프트 바디·눈·막 지느러미·2048² 3장 PBR 텍스처)로 다시 만든 물고기가 들어간 뒤
ReefM1 레벨의 프레임 시간을 `scripts/measure_m2b_perf.sh`로 그대로 다시 측정했다.
개발 전용 `-AquariumFrameStats` 플래그를 쓴다.

## 측정 조건

- 해상도: 1920x1080 (`-game -windowed -ForceRes`), 텍스처 스트리밍 끔
- 씬: 배경 물고기 36마리(5종) + 프롭 14개 + 플레이어 물고기 1마리
- 실행 시간 95초 중 앞 30초(워밍업: 셰이더 컴파일·스트리밍)는 버림
- `-benchmark`는 사용하지 않음 — 고정 타임스텝이 되어 DeltaSeconds가 상수가 되므로 측정에 쓸 수 없다
- 커밋: `85051c7`
- 머신: Apple M5

## SRS 목표 대비

SRS 성능 목표는 "평균 60fps, 95백분위 ≤ 22 ms"이며, **판정은 M6**에서 한다.
이 수치는 에디터 바이너리로 측정한 중간 참고값이다.

폴리곤이 크게 늘고 텍스처가 종당 1장에서 3장(2048²)으로 늘었지만 평균 fps는 0.5%
차이로 측정 노이즈 수준이고, p95/p99는 오히려 조금 낮다. 이 씬은 GPU 바운드가 아니다.
평균 60 fps 기준을 크게 웃돌므로 폴리곤·텍스처를 줄일 이유가 없다.
