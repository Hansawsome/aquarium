# scenario.md — 초등 5~6학년이 재미있어하는 아쿠아리움

작성일: 2026-09-21 · 개정: 2026-09-21 (대상 나이 변경) · 작성: 아쿠부장 · 재미 기획: 키즈부장 · 상태: 논의 합의 완료

## 개정 이력

**초판은 "7살이 처음 앉았다"를 기준으로 썼다.** 사용자가 대상을 **초등학교 5~6학년(만 11~12세)**으로 바꾸면서 전제가 무너져 전면 개정했다. 뒤집힌 판단은 아래 "나이 변경으로 뒤집힌 것"에 따로 적는다. 초판의 판단 중 상당수는 나이와 무관하게 유효하고, **버릴 구현물은 거의 없으며 역할만 바뀐다.**

## 진단 — 왜 지금 심심한가

M0~M6으로 게임은 완성됐다. 아이는 별명을 넣고 입장해 물고기를 배정받고, 방향키로 산호초를 헤엄치고, 물고기를 클릭해 놀래킬 수 있다. 36마리가 무리 지어 헤엄치고 화면은 예쁘다. M7에서 소리도 붙었다.

**그런데 6학년에게 이건 게임이 아니라 화면보호기다.**

7살에게 "세상이 나 때문에 움직였다"가 충분했던 이유는 그 나이엔 **인과관계 자체가 신기하기 때문**이다. 11살은 그 신기함을 이미 다 썼다. 스마트폰 게임을 해 본 아이에게 "클릭하면 반응한다"는 당연한 것이지 재미가 아니다.

> **지금 이 게임에는 아이가 못 하는 일이 하나도 없다. 그게 심심한 이유 전부다.**
> 조용해서가 아니다.

6학년에게 재미는 **"내가 못 하던 걸 하게 되는 것"**이다. 처음엔 안 되다가, 몇 번 해 보니 되고, 친구보다 잘하게 되는 것. 지금은 실패할 수도 없고 늘어날 것도 없다.

판단 기준 문장도 바뀐다: **"이 아이가 이걸 친구에게 보여주고 싶어 할까?"** 지금은 "우리 아빠가 만든 거야" 한 번 보여주고 끝이다. **보여줄 사건이 없다.**

## 축 전환

| | |
|---|---|
| 지금 | 아이가 화면을 건드리면 세상이 반응한다 — **반응의 게임** |
| 바꿀 것 | 아이가 물고기를 몰아서 무언가를 해낸다 — **숙련의 게임** |

주된 동사를 **"클릭한다"에서 "내 물고기로 직접 부딪혀 잡는다"**로 옮긴다.

> 아이가 파란 물고기를 노리고 돌진한다. 놈이 **먼저 눈치채고** 옆으로 튄다. 빗나간다. 다시 붙는다. 놈은 산호 뒤로 파고든다. 아이가 각을 재서 돌아 들어가 **몸통으로 들이받는다.** 「퍽」 — 놈이 튕겨 나가고 머리 위에 아이의 표시가 박힌다. 화면 구석 숫자가 **7 → 8**로 오른다.
>
> 아이: "아 이거 개빠르네." 다시 붙는다.

왜 통하는가: **어렵고**(도망가니 조준이 아니라 추격이고, 관성이 있어 조작에 숙련이 생긴다), **실패가 벌이 아니고**(놓치면 그냥 다시 붙는다), **숫자가 남고**(자랑거리), **처음엔 3마리 나중엔 15마리**가 된다.

## 판단 기준 (5~6학년)

- 읽을 수 있지만 **읽기 싫어한다** — 직접 알아내는 게 더 재미있어서다
- **손이 빠르다.** WASD+마우스·동시 키·연타 전부 된다. 조작이 너무 단순하면 오히려 시시해한다
- **벌은 없되 도전은 있어야 한다.** 되돌릴 수 없는 손해·진행 날리기·타이머 압박은 금지. 하지만 **아무것도 어렵지 않은 것은 벌보다 나쁘다**
- **경쟁을 즐긴다.** 조건은 "한 아이가 계속 지지 않을 것"과 "판이 짧아 바로 다시 할 수 있을 것"
- **유치함을 귀신같이 알아챈다.** 이 나이대가 게임을 끄는 가장 흔한 이유는 어려워서가 아니라 **"이거 애들 거잖아"**다
- **긴장과 공포는 다르다.** 쫓기는 긴장·아슬아슬함·약간의 위협은 **즐긴다**

## 나이 변경으로 뒤집힌 것

| 항목 | 7살 기준 판단 | 5~6학년 판단 | 왜 뒤집혔나 |
|---|---|---|---|
| 낚시꾼 | **기각** — 벌이고 무섭다 | **되살림** (형태 변경: 그물·큰 물고기) | 이 나이대는 쫓기는 긴장을 즐기고, 지금 이 바다에 가장 없는 게 긴장이다. 사용자 직감이 이 나이대에는 맞았다 |
| 클릭=놀래킴 | **1차의 기둥** | **몰이 도구로 격하** | 6학년에게 "클릭하면 놀란다"는 10초짜리 장난감이다. 세 번 해 보고 끝난다 |
| 먹이 | 몰려오는 걸 **구경한다** | **미끼다. 모아 놓고 친다** | 좋은 자리에 뿌리는 것과 아무 데나 뿌리는 것이 달라져 **실력이 갈린다** |
| 무리 갈라짐 | "내가 지나가면 길이 열린다"는 감동 | **속도 계기판** — 속도에 비례해 갈라진다 | 일률적으로 세게 갈라지면 그냥 연출이다. 비례해야 속도를 다루는 재미가 생긴다 |
| 반응 과장 | 1.5배로 팍 부풀기, 「꺅」 | **부풀리지 말고 가속. 삑삑거리지 말고 쿵** | 부풀기는 유아용 카툰 문법이고 이 나이대엔 유치함 신호다 |
| 도장 찍기 | 1.5차 (입구에 어른을 세우면 안 되니까) | **1차** | 11살은 파일 고르기를 혼자 한다. 기각 근거가 무너졌다 |
| 2인 | 협동 위주, 경쟁은 조심 | **경쟁을 넣는다. 서로 방해도 가능하게** | 6학년 둘이 나란히 앉으면 반드시 겨룬다. 안 넣어도 자기들끼리 만든다 |
| 숫자(점수) | 금지 | **쌓이는 숫자 하나는 필요** | 초판의 "점수 금지"는 **잃는 점수**를 말한 것이다. 쌓이기만 하는 숫자는 벌이 아니고, **10분과 40분을 가른다** |
| Q·W·E·R 대사 | 기각 (손이 모자람 + 시시함) | **여전히 기각.** 단 2인용 한정 그림 이모트로 조건부 부활 | 손 문제는 사라졌지만 "게임이 나 대신 말해 주는 것"이 이 나이대엔 **더 빨리** 유치해진다 |

## 결정 사항

| 항목 | 결정 | 이유 |
|---|---|---|
| 중심 동사 | **내 물고기로 부딪혀 잡는다** | 어려움·숙련·수집·자랑이 이 하나에 다 들어간다 |
| 클릭의 역할 | **몰이 도구.** 산호 뒤에 숨은 놈을 클릭해 튀어나오게 만들고, 튀어나온 순간 몸으로 들이받는다 | 클릭이 재미의 목적이 아니라 **기술의 일부**가 된다 |
| 클릭 가르기 | **유지**: 물고기=놀래킴 / 빈물=먹이 | 초판 판단 그대로 유효하다. 동작 하나에 결과 둘이라 아이가 배울 게 없고, 맞히든 빗나가든 쓸모가 있어 실패가 없다 |
| 도장 | **클릭이 아니라 "잡았을 때" 붙는다.** 개수 제한 없음, **떼기 기능 없음**, 세션 동안 유지, 나가기로 리셋 | 떼기는 실수로 잃는 일이 되어 벌이 된다. 쌓이는 것이 재미의 전부다 |
| 도장의 그림 | **기본은 이름표.** 사진은 선택지 | 사진을 안 넣은 아이가 손해 보면 안 된다. 이름표만으로도 "내 거"가 완벽히 성립한다 |
| 사진의 내용 | **"얼굴"로 못 박지 않는다** | 6학년은 자기 얼굴이 게임에 붙는 걸 **부끄러워한다**. 친구가 볼 수 있으면 더 그렇다. 짤·밈·자기가 그린 그림 쪽이 훨씬 웃기고, 프라이버시 걱정도 자연히 가벼워진다 |
| 사진 취급 | **디스크에 복사하지 않고 메모리에만. 게임을 끄면 사라진다** | 아이 사진은 별명보다 민감하다. 같은 원칙을 더 엄격하게 적용한다. 매번 다시 고르는 건 이 나이대엔 문제가 아니다 |
| 숫자 | **화면 구석에 작게 하나.** 점수판·축하 화면·별 세 개 없음 | 숫자 하나면 충분하고, 그 이상은 유치해진다 |
| 완주 보상 | 36마리를 다 찍으면 **바다가 조용히 달라지는 정도.** 축하 화면 금지 | 40분을 버티는 목표가 되되, 선언하는 순간 유치해진다 |
| 위협 | **그물 또는 큰 물고기.** 낚시꾼·낚싯바늘 형태는 쓰지 않는다 | 물속에 사람이 바늘 드리운 그림은 만화적이라 이 나이대에 유치하게 읽힌다 |
| 위협의 벌 | **잡히면 몇 초 갇히고 방향키를 마구 흔들면 빠져나온다.** 잃는 건 시간 몇 초뿐 | 벌을 만들지 않으면서 긴장만 가져온다. 그 몇 초가 아이를 엄청 집중하게 만든다 |
| 위협의 예고 | **36마리가 먼저 한쪽으로 쏠린다.** 안내문 없음 | 아이가 안내 없이 "뭔가 온다"를 안다. **이미 만든 무리 행동의 공짜 재활용**이다 |
| 2인 | **같은 바다에서 각자 도장 찍기, 3분 판, 숫자 두 개만 나란히** | 승리 선언을 띄우는 순간 유치해진다. 이기고 지는 건 둘이 안다 |
| 2인의 안전장치 | ① 판이 짧다 ② 져도 도장이 남는다 ③ **서로 방해할 수 있다** | ③이 가장 중요하다 — **실력 차가 나도 방해는 누구나 할 수 있어** 약한 쪽이 끝까지 재미있다 |
| 소리 | **이미 만든 것 유지.** 단 만화 비명 톤은 재판정 | 나이와 무관하게 필요하다. 다만 물고기가 만화 비명을 지르면 유치함 신호가 된다 |
| 파티클·사운드 그래프 | **Niagara와 MetaSound를 쓰지 않는다** | 에디터 Python으로 만들 수 없어 재현성 제1원칙과 충돌한다(M4b에서 실제로 부딪힌 벽). 해석적 머티리얼과 `USoundWave`+C++로 간다 |

## 연출 문법 — 무엇이 유치하고 무엇이 먹히나

이 절은 구현할 때 계속 돌아볼 기준이다.

**유치하게 읽히는 것 (넣지 않는다)**
- **크기를 1.5배로 부풀리기 — 가장 위험하다**
- 만화 비명 톤
- 동글동글 귀여운 기포
- 알록달록 튀는 색, 반짝이
- 과한 칭찬, "멋져요!", 잘했다는 표시

**먹히는 것**
- **속도.** 순간적으로 튀어 나가는 가속
- **짧은 화면 흔들림.** 부딪힌 순간. 타격감의 9할이 여기서 나온다
- **물이 밀리는 왜곡.** 이 게임은 시각이 사실적이라 아주 잘 어울린다
- 기포는 유지하되 **귀여운 방울이 아니라 난류의 흔적** — 빠르게 지나간 자리에 남는 하얀 줄
- **낮고 짧은 소리** — 「퍽」, 「쿵」, 「촤악」

> **부풀리지 말고 가속시킨다. 삑삑거리지 말고 쿵 한다.**

| 순위 | 무엇 | 상태 |
|---|---|---|
| 1 | **소리** | **구현 완료** — 만화 비명 톤만 재판정 |
| 2 | **부딪혀 잡기 + 도장 + 숫자** | 새 중심축 |
| 3 | **먹이 = 미끼** | 초판 구현 계획 유지, 설명만 바뀜 |
| 4 | **무리 갈라짐을 속도에 비례** | 초판보다 조건 하나 추가 |
| 5 | **위협(그물·큰 물고기)** | 신규 |
| 6 | **2인 겨루기 + 방해** | 신규, 옵션 D 위에서 |
| 7 | 2인 전용 도발 이모트 | 곁가지 |

## 하지 않기로 한 것

- **클릭=놀래킴을 메인으로 두는 것** — 도구로 격하한다
- **부풀기·만화 비명·귀여운 기포** — 유치함 신호
- **혼자 할 때의 말풍선 대사** — 게임이 나 대신 말해 주는 것
- **잃는 점수, 타이머 압박, 진행 날리기, 실패 화면**
- **먹이에 자원 개념** — 게이지·쿨다운·횟수 제한. 화면이 먹이로 하얘질 때까지 뿌릴 수 있어야 한다
- **2인에서 승리 선언 화면**
- **사진을 "얼굴"로 못 박는 것**
- **축하 화면·별 세 개·과한 칭찬**

## 둘이 같이 놀기 — 옵션 D 확정

**맥 한 대, 화면 하나, 아이 둘.** 한 명은 방향키, 한 명은 WASD. **카메라가 고정이라 두 물고기가 애초에 한 화면에 들어와 분할 화면조차 필요 없다** — 고정 카메라라는 초기 결정이 우연히 준 선물이다. 네트워크 0줄, 안드로이드 0, **별명이 기기를 떠나지 않으므로 프라이버시 규칙 개정 0건.** 규모 며칠~1주, M1~M6가 100% 살아남는다.

사용자 결정(2026-09-21): **"같이 앉아서 논다."** 따라서 네이티브 안드로이드·픽셀 스트리밍·웹 클라이언트는 전부 범위 밖이다.

조건 둘: **둘 다 키보드에 손이 닿는지 실제로 앉혀 확인할 것**(안 되면 한쪽을 게임패드로), **내 물고기가 어느 쪽인지 한눈에 구분될 것**(발밑에 옅은 동그라미면 충분, 글자 없이).

참고로 이 검토에서 아쿠부장의 오판 두 가지가 바로잡혔다: **macOS는 픽셀 스트리밍 호스트가 안 된다**(UE 5.8에서는 거짓 — VideoToolbox H.264 인코더가 Metal 리소스로 등록돼 있다), **결정론적 규칙 계층이 싼 멀티플레이를 준다**(열리지 않는다 — `std::uniform_real_distribution`은 구현마다 값이 다르고 `std::sin`도 플랫폼 간 비트 동일이 아니며, 보이즈로 물고기들이 결합돼 있어 1 ULP 차이가 무리 전체로 번진다).

## 제약과 위험

- **재현성 제1원칙**: 모든 에셋은 스크립트로 생성한다. Niagara·MetaSound는 불가.
- **소리 출처**: 배경 CC0는 `docs/ASSETS.md`에 기록. 합성음은 생성 스크립트가 출처다.
- **소리를 끄는 그림 버튼이 필요하다.** 소리를 끄려고 게임을 종료해야 하면 소리를 넣은 것이 손해가 된다.
- **성능**: 현재 61.46 fps는 천장이 아니라 수직동기에 눌린 값이고, 노이즈 바닥은 1.3 fps다. 예비 레버(`GridSizeZ` 128→64, +17.1 fps)는 아직 쓰지 않았다. **측정한다** — M4b에서 "커튼이 제일 비쌀 것"이라는 예측이 측정으로 반증된 전례가 있다.
- **프라이버시**: 별명과 사진 모두 세션 메모리에만. 옵션 D라 네트워크 전송은 애초에 없다.
- **F-11 폐기**: "도망 중 재터치 무시"는 "연타가 기본 사용법"과 양립할 수 없어 폐기했다. 사양 변경이므로 `docs/TASK.md`에도 기록한다.

## 검증 방법

| 계층 | 검증 |
|---|---|
| 규칙 계층 | 추격·포획 판정·도장·먹이 유인을 순수 함수로 만들고 Catch2 테스트를 붙인다(현재 110개). 무리·장애물 회피를 만들 때와 같은 모양 |
| Unreal | Automation 테스트(현재 64개). 새 테스트는 **반드시 일부러 깨뜨려 빨간불을 확인한다** — 이 프로젝트는 아무것도 검증하지 않는 테스트를 여러 번 만들었다 |
| 소리 | 헤드리스로 들어 볼 수 없다. 자동 검증은 "재생 호출이 이 파라미터로 일어났다"까지다. 수동 확인 둘: ① 각 소리가 제때 들리는가 ② **앰비언스를 스피커로 20분** 틀어 놓고 일해 보기(저음이 두꺼우면 아이가 20분쯤 뒤 이유 없이 짜증낸다) |
| 시각 | 같은 맵·시드·입력으로 전/후 클립을 만들어 나란히 본다. 클립을 **실제로 열어서** 본다 |
| **난이도** | **새로 필요한 검증이다.** 잡기가 실제로 어려운지는 테스트로 알 수 없다. 개발자가 직접 해 보고 "처음 3분에 몇 마리 잡았는지"를 기록하고, **아이가 해 본 결과와 비교**한다 |
| 재미 | 키즈부장이 아이 눈으로 읽고, **최종 판정은 아이가 직접 한다.** 자동화할 수 없다 |
