# Aquarium

초등학생이 산호초 바다에서 자기 물고기 한 마리를 조종하는 macOS 아쿠아리움 게임.

## 현재 상태

규칙 계층(C++17, 테스트 103개)과 Unreal 5.8 프로젝트(`unreal/Aquarium`, Automation 테스트 60개)가 있습니다. 한글 별명으로 입장하면 5종 중 한 마리가 무작위 배정되고, 카메라에 가장 가까운 평면에서 이름표를 달고 헤엄칩니다. 배경에는 5종 36마리가 서로 다른 깊이·크기로 유영하고 바닥에는 산호 5종과 바위가 놓여 있습니다(`docs/reviews/`에 검토 영상). 방향키로 내 물고기를 조종할 수 있고(M3), 벽에서는 그대로 멈춥니다. 실사 반복의 첫 단계(M4a)로 물고기 5종을 프로파일 곡선 몸통·눈·막 지느러미로 다시 만들고 종마다 2048² 세 장(베이스 컬러·노멀·러프니스)을 입혀 서브서피스 재질로 바꿨습니다. 두 번째 단계(M4b)로 산호를 3종에서 5종으로 늘려 같은 방식의 PBR 세 장을 입히고, 소품을 22개로 늘려 인스턴스마다 기울기·비균일 스케일·틴트를 주고, 수면에 보이지 않는 그림자 전용 평면을 넣어 **M1부터 남아 있던 "빛줄기 약함"을 해소**했습니다. 함께 안개를 낮추고(10 m 밖에서 색이 다 죽던 문제) 색보정·블룸·SSAO 후처리와 부유 입자를 넣었습니다. 세 번째 단계(M4c)로 같은 종끼리 느슨한 무리를 이루는 보이즈 행동을 넣고(분리는 모든 종, 정렬·응집은 같은 종끼리만), 물고기가 산호·바위를 **부딪히기 전에** 돌아가도록 했으며(내 물고기에도 적용), **M2부터 남아 있던 "수직으로 방향을 바꿀 때 짧은 롤"을 해소**했습니다. 내 물고기는 무리에 끌려들지 않습니다 — 배경 물고기가 피해 갈 뿐입니다. **이로써 실사 반복(M4 a/b/c)은 끝났습니다.** 이어서 M5로 클릭 도망을 넣었습니다 — 물고기를 클릭하면 **가장 앞의 한 마리만** 클릭 지점 반대로 방향을 틀며 2.2배로 가속해 0.8초 도망하고, 1.2초에 걸쳐 원래 상태로 돌아옵니다. 빈 바다를 클릭하면 아무 일도 일어나지 않고, 도망 중에 같은 물고기를 다시 클릭하면 무시되며(이것이 디바운스입니다), 회복 중에 다시 클릭하면 도망이 다시 시작됩니다. 내 물고기도 클릭할 수 있고, 도망하는 0.8초 동안은 누르고 있는 방향키보다 도망이 이깁니다. 적중 판정은 라인 트레이스가 아니라 **해석적 광선–평면 판정**입니다 — 자동 생성된 물리 캡슐이 메시보다 훨씬 뚱뚱해서 빈 물을 맞히고 *가장 앞*도 틀리게 고른다는 것을 실측으로 확인했기 때문입니다. 비용은 **프레임당이 아니라 클릭당**입니다. 성능은 1920×1080 에디터 빌드에서 평균 63.50 fps / p95 16.71 ms로 SRS 목표(60 fps·22 ms)를 충족하지만 여유는 약 5.8 %이고, 비용은 M4b와 마찬가지로 거의 전부 볼류메트릭 안개 격자 한 항목입니다. M4c도 M5도 더한 프레임 비용은 측정에 잡히지 않았습니다(`docs/reviews/2026-09-21-m5-perf.md`). 남은 것은 패키징(M6)입니다. 산호 형상은 아직 1차 품질이라 관 산호가 말뚝 울타리처럼 읽히고 부채 산호가 가지 산호와 잘 구분되지 않으며, 물고기 비늘도 가까이서 보면 겹친 비늘 줄보다는 고운 표면 질감에 가깝습니다.

## 방향

Unreal Engine 5 + Blueprint를 중심으로 구성하고, 테스트할 게임 규칙은 C++로 분리합니다. Blender로 무료 에셋을 수정하거나 필요한 모델과 애니메이션을 제작합니다. macOS 단일 플랫폼이 출시 대상입니다. 태블릿 배포는 2026-09-20 논의로 범위에서 제외했습니다.

그래픽 목표는 실사에 가까운 수중 경험입니다. 실제 품질과 성능은 M5 맥북에서 실행·측정한 결과로 판단합니다.
